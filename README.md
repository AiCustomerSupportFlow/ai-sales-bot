🤖 AI Sales Assistant Bot

AI-ассистент для бизнеса: продажи, поддержка клиентов и сбор заявок с автоматическим дожимом.

---

💡 Что это даёт бизнесу

- 📈 Увеличение продаж за счёт автоответов
- ⏱ Экономия времени менеджеров
- 📥 Автоматический сбор заявок
- 🔥 Дожим клиентов (follow-up)
- 📊 Все лиды в Google Sheets (CRM)

---

⚙️ Как это работает

1. Клиент пишет в Telegram
2. Бот отвечает с помощью AI
3. При интересе — собирает заявку
4. Данные отправляются:
   - менеджеру в Telegram
   - в Google Sheets (CRM)
5. Бот делает follow-up (дожим клиента)

💰 Где можно использовать

- интернет-магазины
- услуги (ремонт, доставка, производство)
- лидогенерация
- поддержка клиентов

🚀 Функционал

- 🤖 AI-ответы (Ollama, локально)
- 💬 Telegram-бот
- 🛒 Сбор заказов (товар, город, телефон)
- 📊 Интеграция с Google Sheets
- 🔔 Уведомления менеджеру
- 🔁 Авто-дожим клиентов
- 🧠 Контекст диалога
- ❗ Обработка возражений

---

🛠 Стек

- Python
- aiogram
- Ollama (mistral)
- Google Sheets API
