# 🤖 AI Sales Assistant Bot

AI-бот для бизнеса: продажи + поддержка + сбор заявок + CRM.

## 🚀 Возможности

- 🤖 AI-ответы (Ollama)
- 💬 Telegram-бот
- 🛒 Сбор заявок (товар, город, телефон)
- 📊 Google Sheets (CRM)
- 🔥 Уведомления о лидах
- 📈 Авто-дожим клиентов
- 🧠 Память диалога
- ❗ Обработка возражений

---

## 🛠 Стек

- Python
- aiogram
- Ollama (mistral)
- Google Sheets API
